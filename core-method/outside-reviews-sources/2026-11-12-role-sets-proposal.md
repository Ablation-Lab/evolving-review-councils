# Role sets proposal (12 Nov 2026)

The source behind [outside-reviews.md](../outside-reviews.md) entry 2, decision 4 (commit 57310ae). Claude, the chat assistant, proposed these role sets in a claude.ai conversation after the review-areas research. I pasted its words here from that conversation. They can't be checked against any local transcript, because claude.ai chats leave none on this machine.

## The proposal, verbatim

> Compare role sets on the same seeds, with every seed tagged by its ISO characteristic. A: current (correctness, security and privacy, docs and policy). B: 3 wide seats (correctness with reliability, performance and the app's tests; security, privacy and safety; docs and consistency with stated intent). C: 5 narrow seats (correctness; reliability and performance; security and privacy; tests; docs). Baseline: one generalist with an ISO checklist, at the same cost. Compatibility, flexibility and interaction capability out on purpose, back later in the running-app tier with the video-review seat.

## How the plan differs from it (checked 12 Nov 2026)

The Claude Docs doc "Seat roles plan" and entry 2's decisions changed the proposal in three places:

| Where | The proposal | The plan |
|---|---|---|
| B, the docs seat | docs and consistency with stated intent | also has clear-cut maintainability |
| C, the security seat | security and privacy | security, privacy and safety |
| C, the docs seat | docs | docs and maintainability |

The proposal doesn't mention maintainability at all; entry 2's decision 2 adds it, limited to clear-cut problems.
